# Excali Clone

A lightweight Excalidraw-inspired drawing app built with vanilla HTML, CSS, and JavaScript.

## Features

- Rectangle, ellipse, line, and pencil tools
- Select and drag existing shapes
- Stroke/fill color pickers
- Delete selected element, clear canvas, and export to PNG

## Run locally

Open `index.html` directly in your browser, or serve the folder:

```bash
python -m http.server 4173
```

Then open <http://localhost:4173>.
